# Magic Learn World 🌟 - Kids Learning Platform

![Magic Learn World Banner](public/assets/logo.png)

Welcome to **Magic Learn World**, an interactive and engaging educational platform designed specifically for kids! This full-stack (MERN) web application makes learning fun through colorful UI, dynamic lessons, and interactive text-to-speech features.

🌐 **Live Demo:** [https://magic-learn-world.vercel.app/](https://magic-learn-world.vercel.app/)

---

## ✨ Features

- **Interactive Learning Modules:** Engaging chapters for English (Alphabets, Colors, Animals), Math (Numbers, Shapes, Signs), and Science (Planets, Nature, Weather).
- **Text-to-Speech (Web Speech API):** Hover over planets and alphabets to hear their names spoken out loud!
- **Dynamic Admin Dashboard:** Full CRUD capabilities to manage subjects, add new chapters dynamically, and update book content.
- **Secure Authentication:** JWT-based login for both Users and Administrators.
- **Fully Responsive:** Beautifully designed to work seamlessly on desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js (Hooks, React Router)
- CSS3 (Custom animations, Flexbox/Grid)
- Swiper.js (For smooth carousels and sliders)
- Axios (For API requests)

**Backend (API & Database):**
- Node.js & Express.js
- MongoDB (Atlas)
- Mongoose
- JSON Web Tokens (JWT) for Authentication

## 🚀 How to Run Locally

If you'd like to run this project on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ishikalimbasiya005/Kids-Learning-Frontend.git
   cd Kids-Learning-Frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your backend API URL (if running the backend locally):
   ```env
   REACT_APP_API_URL=http://localhost:5000
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```

5. **Open in Browser:**
   Navigate to `http://localhost:3000` to view the app!
